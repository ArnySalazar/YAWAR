# Modelo (Jose)

`puntuar.py` hoy es una **versión de prueba** para que la API y el panel avancen. Se reemplaza por el modelo real manteniendo la firma `puntuar(df) -> DataFrame[id_nino, prob_no_consumo, motivos]`.

Entregables: regla simple de 3 variables, regresión logística regularizada y árbol de profundidad ≤3; validación en un año no visto (o por regiones); AUC, calibración y VPP en los N de arriba, por subgrupo y dentro de conglomerado.
